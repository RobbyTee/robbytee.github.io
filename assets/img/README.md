# Drayton Mill photos

The page looks for these files. Until they exist, those sections show a brick-pattern background.

| File | Where it appears | Suggested size |
| --- | --- | --- |
| `drayton-mill-hero.jpg` | Full-screen hero at the top | 2400×1400, landscape |
| `drayton-mill-panorama-{800,1400,2000}.jpg` | "Our roots" section, wide photo above the story (in place) | Same photo at three widths; the browser picks the right one |
| `drayton-mill-towers.jpg` | "Our roots" photo on phones (720px and narrower) | Crop of the main mill and water towers, 620×360 |
| `drayton-mill-2.jpg` | "Built in the Upstate" banner | 2400×1000, wide |

Keep each file under about 400 KB (export as JPEG at quality 70–80).
If you use someone else's photo, add the photographer and license to the footer credits in `index.html`.
